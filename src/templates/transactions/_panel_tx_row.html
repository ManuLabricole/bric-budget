Si on swap innerHTML, le div#tx- reste dans le DOM mais sans ses classes conditionnelles (opacity-40 etc). outerHTML remplace tout l'élément → les nouvelles classes Tailwind et les nouveaux attributs hx-* sont bien présents. Rendu d'une transaction ignorée (is_ignored=True) : - opacity-40 sur le conteneur entier → tout est atténué - line-through sur la description + le montant → signal visuel fort "désactivé" - Bouton œil-slash en doré → indique qu'elle est actuellement ignorée (clic = réactiver) Rendu d'une transaction normale : - Bouton œil en gris, visible au hover seulement - Clic = ignorer {% endcomment %}
